# Sultana Food Industry website

Static one-page site (HTML + CSS + a little JS), built from the "Sultana Food Website Concept" design. No build step is needed.

## Files

- `index.html`: page content
- `styles.css`: styling (brand colors are CSS variables at the top)
- `script.js`: enquiry form; set `WHATSAPP_NUMBER` to send enquiries to WhatsApp
- `vercel.json`: Vercel settings

## Run locally

Open `index.html` in a browser, or run `npx serve .`

## Deploy on Vercel

1. Go to https://vercel.com/new and import this repository.
2. Framework preset: **Other**. Leave the build command and output directory empty.
3. Click **Deploy**. Every push to `main` then redeploys automatically.
